Reconciling that is a change to what the page looks like, not a deduplication. The column ids are the ones stored per user in `UserColumnSettings._default_settings`, so they are a compatibility surface: rename one here and every user who saved that setting silently loses the column. They are also the sort ids: pass a table's `Pagination` as `sort_pagination` and each header becomes a link that sorts on its own column id, which `views/result_sorting.py` looks up to order the rows. That is the `sortable_header_col` widget the listing pages already sort through - the only new thing is that `Pagination` now answers `sort_by` / `is_ascending` / `get_sort_link` the way `CursorPagination` does.
