{#- Marks the parts of `text` that the current search query matched (issue #45). `split_search_matches` hands back (chunk, is_match) pairs of *plain* strings and no markup at all; the element is written here, around an autoescaped `{{ chunk }}`. That is what keeps the feature safe: the search term and the backend name it was found in are both user input, and neither ever passes through |safe or Markup. Do not be tempted to build the marked string in Python instead. See mcritweb/search_highlighting.py. `highlight_terms` is `query|search_terms`; passing nothing marks nothing. -#} {%- macro mark(text, highlight_terms=None, field=None) -%} {%- for chunk, is_match in split_search_matches(text, highlight_terms, field) -%} {%- if is_match -%}{{ chunk }}{%- else -%}{{ chunk }}{%- endif -%} {%- endfor -%} {%- endmacro -%} {%- macro format_monospace(content) -%} {{ content }} {%- endmacro -%} {%- macro format_pichash(pichash) -%} {% set hex_pichash = "0x" + ("%016x"|format(pichash)) %} {{ hex_pichash }} {%- endmacro -%} {%- macro format_offset(offset) -%} 0x{{ "%0x"|format(offset) }} {%- endmacro -%} {%- macro format_family_name(family_name, family_id, highlight_terms=None, highlight_field="family") -%} {% if family_id is none %} {{ mark(family_name or "Unnamed", highlight_terms, highlight_field) }} {% else %} {{ mark(family_name or "Unnamed", highlight_terms, highlight_field) }} {% endif %} {%- endmacro -%} {%- macro format_family_name_tuple(family_name_id) -%} {{ format_family_name(family_name_id[0], family_name_id[1]) }} {%- endmacro -%} {%- macro format_family_id(family_id) -%} {{ family_id }} {%- endmacro -%} {%- macro format_sample_id(sample_id) -%} {{ sample_id }} {%- endmacro -%} {%- macro format_function_id(function_id) -%} {{ function_id }} {%- endmacro -%} {#- A yes/no value drawn as a tick or a cross.
